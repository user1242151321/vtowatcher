FAQ

Common questions.

Do I need a license?

Yes. VTO Watcher uses server-side license validation. A license can also have device, expiration, and version-access limits.

Does VTO Watcher store my Amazon password?

No. The extension works on the Amazon A to Z page already open in your browser and does not need your Amazon password.

How do updates work?

The extension checks the GitHub release feed. When a newer version is available, it can open the current GitHub ZIP download. Because the extension is loaded unpacked, you still extract the update and reload it in Chrome.

Can the extension silently install updates?

No. Chrome does not allow an unpacked extension to silently replace its own local files. The update button downloads the new build; you then replace the files and press Reload.

Can licensing make the extension impossible to copy?

No browser extension can provide perfect DRM because its client-side code exists on the user's computer. VTO Watcher licensing is designed to stop normal unauthorized activation and allow the owner to revoke access.
